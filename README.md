# 🚀 Introducing-SDD | Sistema de Desarrollo y Diseño

¡Bienvenida al repositorio oficial de **SDD**! Este espacio está dedicado a la investigación y estructuración técnica de nuestra iniciativa dentro de **AddonAI** 🌐

### 📋 Sobre el Proyecto
Este repositorio contiene la documentación técnica y los flujos de trabajo iniciales para el sistema de desarrollo de la startup. Aquí centralizamos:

* 🏗️ **Estructura HTML**: Base de la interfaz de investigación.
* 📄 **Metodología**: Documentación detallada sobre procesos de desarrollo.
* 🧠 **Lógica de Sistemas**: Integración de flujos de trabajo optimizados.

### 🛠️ Tecnologías en uso
* **Frontend**: HTML5 y CSS con un enfoque minimalista.
* **Versicionamiento**: Git + GitHub para un despliegue seguro.
* **Entorno**: VS Code en Windows con configuración SSH.

### 📂 Estructura del repositorio
* `sdd-investigacion.html`: Prototipo inicial de la plataforma de investigación.
* `Documentación/`: Archivos PDF y Word con la metodología de la startup.
